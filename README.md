# By Ege

**By Ege** is Ege Uysal's personal blog website. You can contact me at [hi@egeuysal.com](mailto:hi@egeuysal.com) for contributions, collaborations, or questions.  

Check out my portfolio at [https://egeuysal.com](https://www.egeuysal.com).  

## Features
- Clean, minimalist design  
- Mobile-first and responsive  
- Markdown-based posts for easy content creation  
- Dark and light mode support  

## Contributing
Want to add a blog post, suggest a feature, or report a bug? Reach out via email or submit a pull request if you’re comfortable with Git.  

## Tech Stack
- Frontend: Next.js, Tailwind CSS, React  
- Markdown rendering with React Markdown  
- Deployment: Vercel / Static hosting
